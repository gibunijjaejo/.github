# 기분이짜져 (gibunijjaejo)

### 학생이 학생을 위해 만드는 개발 팀

> 학업이 막막한 순간, 우리가 만든 도구가 길을 보여주길 바랍니다.

서강대학교 컴퓨터공학과 학생 4인이 모여 **서간표(Seoganpyo)** — AI 기반 학업 컨설팅 플랫폼을 함께 만들고 있습니다.

</div>

---

## 우리는

- **학생의 진짜 불편**에서 출발합니다. 시간표 짜기, 졸업 요건 확인, 강의 선택 — 매 학기 반복되는 막막함을 코드로 풉니다.
- **풀스택 전 영역**을 직접 다룹니다. 백엔드 · 프론트엔드 · AI/LLM · 인프라/모니터링까지 4인이 나눠 맡아 끝까지 책임집니다.
- **만들면서 배웁니다.** 처음 써보는 기술이라도 일단 붙어보고, 동작하는 서비스로 완성합니다.
